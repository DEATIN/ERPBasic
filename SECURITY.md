# Безопасность

## Текущие границы

Эта версия хранит данные в браузере. В ней нет серверной авторизации, разграничения доступа между сотрудниками и защищённой общей базы. Для проверки используйте демонстрационные сведения.

Резервные копии и выгрузки содержат введённые пользователем данные. Храните их с учётом содержимого и не прикладывайте рабочие файлы к публичным задачам.

## Сообщение об уязвимости

Для уязвимости, которая может раскрыть данные или выполнить посторонний код, используйте приватное сообщение об уязвимости в разделе безопасности GitHub, если он включён. При его недоступности напишите на **support@clientora.ru** с темой «ERP Basic: сообщение об уязвимости».

Укажите версию, шаги воспроизведения, последствия и безопасный пример на вымышленных данных. Не включайте пароли, ключи, действующие токены и сведения клиентов.

Обычные ошибки интерфейса можно описывать через публичную форму ошибки.
