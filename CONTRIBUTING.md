# Как внести вклад

Документация, описания задач, обсуждения, комментарии к коду и сообщения коммитов ведутся на русском языке. Названия стандартных файлов, протоколов и программных интерфейсов сохраняются в принятом техническом формате.

## Перед изменением

1. Найдите существующую задачу или создайте новую через форму ошибки либо предложения.
2. Опишите конкретный сценарий и ожидаемый результат.
3. Для изменения учётной логики укажите, как оно влияет на документы, деньги, остатки и повторное проведение.

## Работа с кодом

Создайте отдельную ветку. Сохраняйте текущую компоновку и поддержку двух тем. Тексты кнопок, ошибок и подсказок должны быть на русском языке. Новые внешние зависимости добавляйте только при понятной необходимости.

Для изменений расчётов и проведения добавляйте проверку поведения, а не копию формулы из реализации. Для изменений оформления проверьте результат в браузере, в обеих темах и на узком экране.

```bash
npm run проверка
npm run тесты
```

## Оформление изменений

Используйте понятное русское название: «Исправлен расчёт задолженности после возврата», «Добавлен фильтр поставщиков». В описании укажите задачу, результат, способ проверки и существенные ограничения. Приложите снимки экрана, если меняется интерфейс.

Не включайте в изменения рабочие резервные копии, персональные данные, пароли, ключи доступа и настройки частных систем.
