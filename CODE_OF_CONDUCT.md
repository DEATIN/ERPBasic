# Правила общения

Рабочий язык проекта — русский. Обсуждайте задачу, поведение программы и проверяемый результат.

- Пишите уважительно и по существу.
- Разделяйте подтверждённую ошибку и предположение.
- Для замечания предлагайте воспроизводимый пример или объяснение последствий.
- Не публикуйте чужие персональные данные и закрытую переписку.
- Не используйте оскорбления, угрозы и дискриминационные высказывания.

Если обсуждение зашло в тупик, зафиксируйте варианты и их последствия. Решение по включению изменения принимает сопровождающий проекта.
