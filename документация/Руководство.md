# Руководство пользователя

## Начало работы

Запустите локальную страницу по инструкции в README. Приложение откроет рабочее пространство продаж с вымышленными данными. Панель слева переключает модули, соседнее меню — страницы выбранного раздела. Верхняя панель содержит действия текущей страницы и переключатель темы.

## Заказ и оплата

1. Откройте **Продажи → Заказы клиентов**.
2. Создайте документ, выберите клиента и добавьте товары или услуги.
3. Проверьте количество, цену, скидку, дату и итоговую сумму.
4. Сохраните документ и подтвердите его.
5. Создайте связанную реализацию через действия документа.
6. Зарегистрируйте оплату. Для проверки частичной оплаты введите сумму меньше общей задолженности.
7. Откройте список оплат и отчёт по задолженности: связанные суммы должны соответствовать документам.

## Закупка и поступление

Создайте заказ поставщику в модуле закупок. Оформите поступление на его основе, проверьте строки и подтвердите документ. Затем откройте остатки на складе. Повторное подтверждение того же поступления не увеличивает количество повторно.

## Работа со списками

Используйте поиск и фильтры для отбора. Меню колонок позволяет оставить нужные поля. Выбор строк ограничивает состав выгрузки. Заголовки и значения CSV сохраняют разделители и переносы внутри полей.

## Импорт

Сначала скачайте шаблон из соответствующего действия приложения. Сохраните названия и порядок колонок. Загрузите CSV и изучите результат проверки. Подтверждайте импорт после исправления ошибок. Для номенклатуры существующие коды обновляются; для банковского примера платежи связываются с демонстрационными заказами.

## Резервная копия

Перед очисткой данных откройте настройки и сохраните резервную копию JSON. Файл содержит документы и справочники локальной модели. Восстановление выполняйте в демонстрационном окружении после сохранения текущей копии.

Данные привязаны к браузеру и адресу страницы. Локальная версия, GitHub Pages и версия Clientora используют отдельные хранилища. Для переноса между ними требуется выгрузка и восстановление.

## Частые вопросы

**Данные увидит другой сотрудник?** Нет, в этой версии общей серверной базы нет.

**Можно вести официальный бухгалтерский учёт?** Текущая версия предназначена для проверки интерфейса и управленческих сценариев. Регламентированный учёт не реализован.

**Работает ли обмен с Clientora?** Раздел обмена демонстрирует предполагаемые действия и состояния. Реальное подключение пока не реализовано.

**Почему после смены браузера нет документов?** Локальное хранилище браузеров раздельное. Используйте резервную копию для проверки переноса.

**Это установленный ERPNext?** Нет. Это самостоятельный интерфейс. Совместимость с документами и механизм перехода находятся в плане развития.
