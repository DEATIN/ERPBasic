# Совместная работа и инструменты GitHub

## Обсуждения и задачи

Вопросы по использованию, идеи и примеры обсуждаются в [Discussions](https://github.com/DEATIN/ERPBasic/discussions). Для воспроизводимой ошибки или конкретного предложения используйте [задачи](https://github.com/DEATIN/ERPBasic/issues). Формы и рабочие тексты проекта — на русском языке.

Сопровождающий проекта — **@DEATIN**. Правила участия находятся в CONTRIBUTING.md, правила общения — в CODE_OF_CONDUCT.md. Уязвимости передаются приватно через раздел безопасности.

## Изменения кода

Рабочий процесс: отдельная ветка → запрос на изменение → проверки → слияние в основную ветку. Для основной ветки используются обязательные проверки. Завершайте обсуждения до слияния. Название и описание изменения пишите по-русски.

GitHub запрашивает проверку сопровождающего через CODEOWNERS. Для готового запроса можно включить автоматическое слияние после выполнения требований. Ветка слитого запроса удаляется автоматически; история изменения остаётся в репозитории.

## Проверки и обновления

Проверки интерфейса, модели учёта и сборки выполняются в GitHub Actions. CodeQL анализирует JavaScript, Python и определения действий GitHub. Включены граф зависимостей, оповещения Dependabot, проверка на вредоносные зависимости и защита от публикации секретов.

Dependabot проверяет версии действий GitHub еженедельно, по понедельникам в 09:00 по Москве. Обновления группируются в запросы на изменение. Отдельный обработчик оформляет запросы официального бота по-русски, используя только метаданные запроса. Обновления проходят обычные проверки перед слиянием.

## Выпуски

Стабильный снимок демонстрации публикуется в [выпусках](https://github.com/DEATIN/ERPBasic/releases). Процесс «Подготовка выпуска ERP Basic» запускается вручную из основной ветки. Укажите версию вида `v0.3.0`, совпадающую с package.json, и признак предварительного выпуска.

Процесс проверяет код и учётные сценарии, собирает архив, формирует SHA-256 и подтверждение происхождения GitHub. Файлы прикрепляются к черновику; после этого выпуск публикуется. Для опубликованных выпусков включена неизменяемость: исправления оформляются новым выпуском.

Проверка скачанного архива:

```bash
gh attestation verify ERPBasic-v0.3.0.zip --repo DEATIN/ERPBasic
```

Контрольная сумма также находится в файле `.zip.sha256`, а подтверждение подписи — в `.sigstore.json`.

## Среда разработки

Конфигурация `.devcontainer/devcontainer.json` задаёт Node.js 22, Python 3.12 и проброс порта 8000. Она подходит для локальных Dev Containers и GitHub Codespaces. Облачный запуск учитывается в квоте аккаунта GitHub.

После создания среды выполняются проверки. Для запуска интерфейса используйте:

```bash
python3 инструменты/запуск.py
```
